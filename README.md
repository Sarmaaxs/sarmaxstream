## About SarmaxStream

SarmaxStream is a media-focused application designed to make discovering, playing and managing media feel straightforward. It brings a clean browsing and playback experience together with convenient ways to keep track of content.

The project is focused on making media access feel simple across supported devices, including features for managing available offline items where browser support allows.

## Highlights

- **Discover and browse** — explore available media through the application.
- **Playback experience** — listen and manage playback from within the app.
- **Downloads library** — view and manage supported items saved for offline access.
- **Convenient access** — designed as a browser-based experience.
